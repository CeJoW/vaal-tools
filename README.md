# vaal Tools

Инструменты удобства игрока для **Pathfinder Second Edition** на **Foundry VTT 14**.

## Статус

Начальный каркас 0.1.0: регистрация модуля и персональной настройки оповещений, русский и английский языки. Автоматические оповещения и выполнение реакций пока не реализованы. Совместимость в живом мире ещё не проверена.

## Направление разработки

Модуль будет обнаруживать игровые события и предлагать владельцу персонажа подходящие реакции. Поддержка добавляется постепенно, по одной способности. Каждая реакция должна иметь отдельный обработчик условий и выполнения.

Для каждой реакции проверяем способность персонажа, условия события, доступность реакции и права пользователя. Игрок принимает или отклоняет предложение; перед выполнением условия проверяются повторно. Нужны защита от повторных уведомлений и проверка в сессии мастера и игрока.

## Локальная установка

Скопируйте папку проекта под именем `vaal-tools` в `Data/modules` вашей установки Foundry. Файл `module.json` должен находиться непосредственно внутри `Data/modules/vaal-tools`. Перезапустите Foundry и включите **vaal Tools** в управлении модулями мира PF2e.

Сборка не требуется. Точка входа: `scripts/main.js`. Не храните в репозитории игровые миры, данные персонажей, пароли или ключ лицензии Foundry.
