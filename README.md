# vaal Tools

Инструменты удобства игрока для **Pathfinder Second Edition** на **Foundry VTT 14**. Текущая версия — **0.2.5**.

## Возможности

- Inevitable Return: проверка способности в чарнике, размера Small/Medium, враждебности, дистанции до 30 футов и доступности реакции; предложение игроку и мастеру в чате с кнопками «Да / Нет».
- Создание одного тралла на месте погибшего через PF2e Summons Assistant и TCAL. Тело скрывается, но не удаляется.
- Отмена связанного летального урона PF2e удаляет созданного тралла и возвращает видимость тела. Реакция возвращается только если состояние её расхода не изменилось. Для ручной отметки смерти без сообщения урона такой связи нет.
- Общий счётчик реакций в чарнике и кнопки USE: использование любой обычной реакции расходует общий запас 1/1 и публикует способность в чат. Броски и эффекты других реакций разрешаются обычным способом.
- Восстановление в начале хода, отдельный запас Endless Return, ручное восстановление владельцем персонажа кнопкой ↺ или через Alt+R.

## Установка и настройка

Скопируйте папку проекта под именем `vaal-tools` в `Data/modules`: файл `module.json` должен находиться непосредственно внутри `Data/modules/vaal-tools`. Перезапустите Foundry и включите модуль в мире PF2e вместе с обязательными зависимостями. Сборка не требуется; точка входа — `scripts/reactions.js`.

Автоматизация расстояний работает только в **футах**. Для обычной боевой карты PF2e настройте сцену: Grid → Distance = 5, Units = ft. На сценах с другими или неизвестными единицами дистанционные реакции блокируются с предупреждением. Подробнее: [INTEGRATIONS.md](INTEGRATIONS.md).

Для автоматизации нужен активный мастер на сцене. Смерть определяется статусом Dead либо Defeated при 0 HP без dying/unconscious; одних нулевых HP недостаточно. Ручное восстановление общего запаса не возвращает индивидуальные лимиты frequency способностей. Реакции, использованные вне кнопок vaal Tools, отмечаются через Alt+R.

## Проверка

Локальный сценарий проверялся совместно с пользователем на Foundry 14.368 / PF2e 8.5.1. Автоматические проверки логики: `node --test tests/core.test.mjs`. Подробный сценарий и ограничения: [TESTING.md](TESTING.md). Не все перечисленные крайние случаи подтверждены проверкой в живом мире.
