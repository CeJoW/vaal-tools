# Единицы измерения и внешние модули

## Только футы

Проверка дистанции Inevitable Return поддерживает только сцены с единицами `ft`, `feet`, `foot` или русскими обозначениями футов. Метры, неизвестные и пустые единицы блокируют предложения и использование старых карточек; выводится предупреждение. Пересчёт метров не выполняется.

В настройках сцены откройте Grid / Сетка. Для стандартной боевой карты PF2e задайте Grid Scale / Distance = 5 и Units = ft (клетка 5 футов). Размер клетки в пикселях определяется изображением карты. Одной смены подписи с метров на футы недостаточно: проверьте масштаб карты и расстояния линейкой. Единицы задаются для каждой сцены отдельно.

## Inevitable Return

- PF2e Summons Assistant (chasarooniZ), проверенный исходный код версии 2.20.2: https://github.com/ChasarooniZ/pf2e-summons-assistant . vaal Tools динамически вызывает `getSpecificSummonDetails` из `scripts/specificSummons.js` для Inevitable Return. Используются шаблон тралла, оформление и эффект срока жизни. Этот внутренний интерфейс может измениться при обновлении зависимости.
- Transient Compendium Actor Library / TCAL (ddbrown30), версия 1.2.0: https://github.com/ddbrown30/tcal . Используется `game.tcal.importTransientActor` для подготовки актора тралла перед размещением токена на месте погибшего.
- PF2e Toolbelt: при наличии используется совместимый флаг `shareData` для связи событий времени с некромантом; код модуля не импортируется. Это необязательная интеграция.
- Foundry Summons, socketlib и другие зависимости Summons Assistant устанавливаются по его собственному манифесту. Функция выбора места Foundry Summons напрямую не вызывается: позиция задаётся местом погибшего.

Обязательные прямые зависимости указаны в `module.json` → `relationships.requires`. Исходный код сторонних модулей не включён в vaal Tools; сторонние шаблоны и эффекты принадлежат их правообладателям и предоставляются установленными зависимостями. Указание авторства не заменяет их лицензионных условий.
